# Gjurmuesi Im

Regjistro aktivitetet e ditës dhe shiko timeline-in tënd me statistika javore.

## ✨ Veçoritë

- ➕ Shto aktivitete me emër, kategori (💼 Punë, 🏃 Sport, 📚 Lexim, 🎮 Argëtim, 🍽️ Ushqim, 😴 Pushim) dhe kohëzgjatje
- 🕘 Timeline e grupuar: Sot, Dje, dhe data (rend zbritës)
- 📊 Statistika: sot gjithsej, java gjithsej, mesatarja ditore
- 📈 Grafik me shtylla për 7 ditët e fundit + top 3 kategoritë me %
- 🗑️ Fshi aktivitete veç e veç ose pastro të gjitha (me konfirmim)
- 💾 Ruajtje lokale në browser (localStorage) — 100% demo, pa server
